# 「もしも政治」X 予告プロモーション ― 各政党の「公約と結末」4コマ

作成：2026-09-26　／　対象：X（旧Twitter）の予告投稿（テキスト＋4コマ画像）

## 0. 企画の前提

- **コンセプト**：「もしも、この公約が実現したら？」を、ふつうの家庭や街の一日として描く4コマ。政策の良し悪しを語るのではなく、暮らしの中で起きる小さな変化を描く。
- **公平性のルール**
  - 全政党を同じ形にする。起＝公約が暮らしに届く、承＝喜ぶ人、転＝別の立場の人の戸惑いや心配、結＝人と人のやりとりで締める。
  - どの党にも、喜ぶ人と戸惑う人の両方を描く。結末で党を持ち上げたり落としたりしない。
  - 投稿順は衆院議席数順（2026年2月衆院選）。党名のハッシュタグは付けない。
- **公約の出どころ**：主に2026年2月の第51回衆院選の公約（自民は2025年参院選公約）。要旨であり原文ではない。
- **投稿前の確認**
  - 選挙期間中は投稿しない。公職選挙法上の扱いを事前に確認する。
  - 公約の要旨が各党の最新の公式発表と食い違っていないか見直す。
  - 中道改革連合は2026年9月に分裂し、公明党と民主改革の会に分かれた。表記に注意する。
  - 減税日本・ゆうこく連合は公約データ未収録のため、今回は対象外。

### 全投稿に付ける注記（画像の下部 or リプライ）
> ※フィクションです。公約は各党の公約の要旨で、登場人物と出来事は想像上のものです。特定の政党への支持・不支持を呼びかけるものではありません。

## 1. 画像生成の共通設定

### 4コマの仕上げ
- 1コマずつ 16:9 で生成し、縦に4枚並べて1枚の画像にする（全体 1080×2400 程度）。
- **画像には文字を入れない**。セリフの吹き出し、コマ番号（起・承・転・結）、タイトル帯「もしも〇〇党の公約が実現したら」、注記は、生成後に重ねる。
- 同じ話の4コマで人物の見た目がぶれないよう、各話の「登場人物」の説明を毎コマのプロンプトにそのまま含める。

### 共通スタイル（下の各プロンプトには展開済み。そのままコピーして使える）

### 共通ネガティブプロンプト
```
文字、英字、キャプション、吹き出し、読める看板、ロゴ、政党のマーク、選挙ポスター、実在の人物、政治家、有名人、写実的な写真、3DCG、流血、暴力、透かし、署名、ぼやけ、指の崩れ、顔の崩れ
```

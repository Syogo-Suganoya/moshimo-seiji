# 「もしも政治」X 予告プロモーション ― 各政党の公約と、街の反応

作成：2026-09-26　／　対象：X（旧Twitter）の予告投稿（テキスト＋画像4枚）

## 0. 企画の前提

- **コンセプト**：「もしも、この公約が実現したら？」に、ゲームの中の街の人がどう反応するかを見せる。政策の良し悪しを語るのではなく、立場によって受け止め方が違うことを見せる。
- **公平性のルール**
  - 全政党を同じ形にする。1枚目＝公約の文字、2・3枚目＝喜ぶ属性、4枚目＝疑う属性。
  - どの党にも、喜ぶ人と首をかしげる人の両方を出す。並びはゲームの数値で機械的に決め、党を持ち上げたり落としたりしない。
  - 投稿順は衆院議席数順（2026年2月衆院選）。党名のハッシュタグは付けない。
- **公約の出どころ**：主に2026年2月の第51回衆院選の公約（自民は2025年参院選公約）。要旨であり原文ではない。
- **投稿前の確認**
  - 選挙期間中は投稿しない。公職選挙法上の扱いを事前に確認する。
  - 公約の要旨が各党の最新の公式発表と食い違っていないか見直す。
  - 中道改革連合は2026年9月に分裂し、公明党と民主改革の会に分かれた。表記に注意する。
  - 減税日本・ゆうこく連合は公約データ未収録のため、今回は対象外。

### 全投稿に付ける注記（画像の下部 or リプライ）
> ※フィクションです。公約は各党の公約の要旨で、反応と数値はゲーム内のシミュレーションです。特定の政党への支持・不支持を呼びかけるものではありません。

## 1. 画像の作り方

- 1投稿に画像4枚（X の上限）。1枚目は公約の文字（画像生成）、2〜4枚目はリアクション。
- リアクションは、ゲームでその公約を表明したときの属性ごとの支持率の変化（公約データの `fx`）から、代表的な属性を1枚に2つ、1人ずつ。数値の大きい順に並べ、2枚目が一番喜ぶ側、4枚目が一番疑う側。`fx` が6つに満たないときは、変化なし（±0）の属性で補う。
- 記者クラブなど、属性でない話者は入れない。セリフは、公約データの反応があればそれを使い、ないものはゲームの口調で書く。
- 吹き出しは HTML と CSS、人物は[いらすとや](https://www.irasutoya.com/)のイラスト。属性とイラストの対応、党ごとのセリフは [promo/build.py](promo/build.py) にまとめてある。
- 作り直すとき：
  ```bash
  python3 docs/promo/build.py
  ./docs/promo/shot.sh ldp
  ```
  `shot.sh` は Mac の Google Chrome で `docs/promo/images/<党名>/2.png`〜`4.png`（1280×720）を書き出す。1枚目（画像生成）は同じディレクトリに `1.png` として置く。
- **いらすとやの規約に注意**：よくある質問で「選挙運動、また特定の個人や団体を批判する目的には利用できません」とされている。ゲームの宣伝で政治的な主張はしないが、政党の公約を扱うので、選挙期間中は使わない。公開前に規約を読み直し、迷うときはいらすとやに問い合わせる。商用で21点以上使う場合は有償。

### 1枚目（画像生成）のネガティブプロンプト
```
英字、キャプション、指定した見出し以外の文字、読める看板、ロゴ、政党のマーク、選挙ポスター、実在の人物、政治家、有名人、写実的な写真、3DCG、透かし、署名、ぼやけ
```
- 日本語の文字が崩れたときは、文字の指定を消して生成し直し、見出しを後から重ねる。

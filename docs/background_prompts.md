# 背景パターンの画像生成プロンプト

作成：2026-09-26

## 方針
- 背景はターンごとに生成しない。**7パターンを事前に生成**しておき、状況に応じて差し替える。
- 住民アイコンを画像の決まった位置に重ねるため、**7枚とも構図（建物の配置）を同じにする**。変えるのは空・天気・時間帯・街の状態だけ。
- 画像に文字は入れない（看板・プラカードも文字なし）。
- サイズ：3200×1800（16:9）。スマホでは横スクロールで表示する。

## 差し替えの条件（上から優先）
| ID | パターン | 条件 |
|---|---|---|
| disaster / tension / stall | 災害／緊張／停滞 | 危機が発生中（台風＝災害、関税＝緊張、円安＝停滞） |
| ruin | 荒廃 | 内閣支持率 25%未満 |
| tension | 緊張 | 米国の支持 30未満、または中国 20未満 |
| stall | 停滞 | 内閣支持率 38%未満 |
| urban | 都市化 | 都市化の度合いが +4 以上（成長投資・AI・半導体・再開発などの政策で上がる） |
| rural | 地方化 | 都市化の度合いが −4 以下（農業・防災・地方・移住などの政策で下がる） |
| good | 順調 | 上記以外 |

## 仕上げのチェック
- 7枚を重ねて切り替えたとき、建物の位置が一致しているか（住民アイコンの位置は `SPK` の x・y、1600×900基準）。
- 各パターンで住民アイコン（丸いピン）が背景に埋もれないか。暗いパターン（荒廃・災害）は、アイコンの周りを明るめに残す。
- スマホ（縦長）で横スクロールしたとき、左右端の住民（農家・中国・諸外国）が見切れないか。
